Overview

Forge encode/decode helpers for mesh payloads in pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/forgemesh.git
cd forgemesh
node src/cli.js --help
node --test
